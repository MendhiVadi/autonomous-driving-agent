# Two-PC development checklist

1. Verify each computer's interfaces, addresses and certificate fingerprint.
2. Apply the scoped firewall rule and test TLS authentication.
3. Run brake-held reset/step diagnostics using Town02_Opt.
4. Test disconnect, cable pull, reconnect and host cleanup.
5. Measure latency and rendered frame rate during sustained operation.
6. Validate traffic scenarios, observations and rewards before adding the trainer.

See [connection setup](CONNECT_SECOND_PC.md) and [validation status](VALIDATION.md).
