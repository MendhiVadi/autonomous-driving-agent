# Shared AI instructions

Read `README.md` first. This repository is one Windows application; there are
no sibling laptop folders, vaults or two-PC transfer tools any more.

- Keep exactly three `.cmd` files at the root: `run_car.cmd`, `run_neural.cmd`
  and `run_large_map_neural.cmd`. New behaviour goes behind options of
  `scripts/launch.ps1` or into `app/`, not into new launchers.
- Run `tools/verify.py` before committing. It needs no simulator; without the
  real `carla` package the stub in `tests/stubs` is used automatically.
- Never commit `logs/`, `episodes/`, `exports/`, credentials or CARLA binaries.
  Do commit `nn_policy_colab.json` when a trained model exists.
- `nn_policy_bootstrap.json` is generated by `tools/train_bootstrap_policy.py`;
  regenerate it instead of editing it.
- The runtime only works on Windows with CARLA 0.9.16 installed; do not claim
  live verification without running a session on such a machine.
- Hardware evidence for this laptop (DX11 camera hangs, thermal cooldown,
  readback alignment) lives in `docs/CRASH_DIAGNOSIS.md`; preserve it when
  changing renderer or camera defaults.
